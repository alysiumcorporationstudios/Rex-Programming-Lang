    Standard library¶

    Everything in Rex lives under the rex namespace, so a script never collides with the language itself. This page is generated from the interpreter source by scripts/gen_stdlib_docs.py, so it always matches the shipped behaviour.

    rex.show("Sawubona")                                    # printing
rex.let post = rex.get("https://example.com/api/1")     # HTTP
rex.show(post.title)                                    # property access
rex.let slug = rex.replace(rex.lower(post.title), " ", "-")
rex.write("post.txt", rex.json.stringify(post, true))

    Behaviour worth knowing¶

    • Numbers are integers or floats. Division always produces a float; rex.math.round(x) returns an integer when you ask for 0 digits.
    • Strings support ${...} interpolation in double quotes only. Single quotes are literal.
    • Truthiness: null, false, 0, 0.0, "", [] and {} are false; everything else is true.
    • Equality is structural and type aware, so 1 == true is false.
    • HTTP builtins return parsed JSON when the response is JSON, otherwise the response text. Use rex.request() when you need the status code or headers.
    • HTTP errors are catchable Rex errors: a 404 raises, so wrap calls in rex.try / rex.catch when a missing resource is expected.
    • Files are read and written as UTF-8. rex.write creates parent directories for you.
    • Copies vs mutation: rex.sort, rex.reverse, rex.unique and rex.clone return copies. rex.push and rex.pop mutate in place, which is what you want inside a loop.
